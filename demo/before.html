Core

Five Core Disciplines

The principles that keep every page honest, branded, and free of template feel.

🎯

Signature from Content

The memorable element comes from the content itself — real data, real product UI, real process. Decoration either encodes information or gets deleted.

🎨

One Accent Color

Only one hue family gets to shout; everything else stays neutral. Spend it as text, hairlines and small marks — never as large fills.

📐

Type Scale as Personality

Tight-tracked headlines against quiet data micro-labels beat swapping fonts. Radius vs. square corners is a brand decision — pick one.

✂️

Subtract

Ask of every element: what breaks if I delete it? The Chanel principle — take one accessory off before leaving the house.

🀄

CJK Semantic Line-Breaking

Break long Chinese headlines into inline-block semantic chunks — no orphan characters stranded on their own line.

🧭

One Argument per Page

Information hierarchy scannable in 3 seconds; each screen carries exactly one core argument.

Process

A Gated Workflow

No code until the plan survives the checklist.

1

Confirm the Style Anchor

The gating decision — it determines palette, type, layout and signature. Get it wrong and you redo the whole design system.

2

Distill, Don't Skin-Copy

Reference sites are distilled into design systems — 4–6 named colors, type tiers, layout concept, signature — never copied pixel by pixel.

3

Plan Self-Check

Would this scheme still work for different content? If yes, it is a template — start over. No code until the plan passes.

4

Build

Single file, zero external dependencies. System sans first, tabular numerals, one choreographed motion sequence with reduced-motion fallback.

5

Screenshot Self-Check

Never deliver blind. Headless Chrome screenshots, inspected with your own eyes — fix line-breaks, overflow and contrast, then re-shoot.

6

Pre-Delivery Checklist

Content truthfulness, design discipline, engineering quality, contrast and states — walk every item before shipping.

Anti-Patterns

The AI-Default Reject List

Checked line by line before building — any hit means redo.

✖Cream base + serif display headlines + terracotta orange — the editorial-magazine skin
✖Near-black base + single neon-green accent — the hacker/acid skin
✖Newspaper hairlines + zero radius + dense multi-column — the broadsheet skin
✖Deep-space base + blue-violet glow + glassmorphic cards — the 2021 AI standard kit
✖Generic SaaS card grid — light-gray base, white cards, left gradient bar, chip badges
✖Decoration unrelated to content — mosaics, particles, wave SVGs that are only "pretty"
Quality

Pre-Delivery Checklist

Walk every item. Any failure means go back and fix it.

✅ Every numeral matches the source data — multiples and percentages survive arithmetic
✅ Single accent color; every usage matches a declared role; no large-area fills
✅ Zero external dependencies — no web fonts, CDN images, or icon libraries
✅ Body text contrast ≥ 4.5:1, large text ≥ 3:1, focus ring ≥ 2px at ≥ 3:1
✅ Disabled, loading, empty and error states built — not forgotten
✅ Headless Chrome screenshots inspected: first screen, full-length, narrow viewport
