A skill for Claude Code / Kimi Code agents

Modern is not a fixed look. It is the inevitable form of the specific content.

A design playbook for building distinctive, engineering-rational web pages that reject the “AI default look”. Every page needs a reason why only it could look this way.

01

Five core disciplines

1.1

Signature from content

The element a page is remembered for comes from the content itself — real data, real product UI, real process. Decoration either encodes information or gets deleted.

1.2

One accent color

Only one hue family gets to shout; everything else stays neutral. Spend the accent as text, hairlines and small marks — never as large fills. This page spends it on section-index bars, the hero key phrase, and the primary CTA. Nothing else.

1.3

Type scale is personality

Tight-tracked headlines against quiet micro-labels beat swapping fonts. Radius versus square corners is a brand decision — pick one and stay consistent site-wide.

1.4

Subtract

Ask of every element: what breaks if I delete it? The Chanel principle — take one accessory off before leaving the house.

1.5

Semantic line-breaking for CJK

Long Chinese headlines are broken into inline-block semantic chunks, so the browser only wraps between chunks — no orphan characters on their own line.

02

A gated workflow — no code until the plan passes

2.1

Confirm the style anchor

The gating decision. It determines palette, type, layout and signature — get it wrong and the whole design system gets redone. This page is anchored on the Claude Code engineering-rationalism case.

2.2

Distill, don’t skin-copy

Reference sites are distilled into a design system — 4–6 named colors, type tiers, one layout concept, one signature — never copied pixel by pixel.

2.3

Plan self-check

Would this scheme still work for different content? If yes, it is a template — start over. No code until the plan survives the anti-pattern list line by line.

2.4

Build with zero dependencies

Single file. System sans first, tabular numerals, mono reserved for code and identifiers. One choreographed motion sequence, with a prefers-reduced-motion fallback.

2.5

Screenshot self-check

Never deliver blind. Headless Chrome screenshots, inspected with your own eyes — fix line-breaks, overflow and contrast, then re-shoot. This page passed the same check.

04

The AI-default reject list

✕

Cream base + serif display + terracotta— the editorial-magazine skin. Answering “modern” with this is answering the wrong question.

✕

Near-black base + neon-green accent— the hacker/acid skin. Overused.

✕

Newspaper hairlines + dense multi-column— the broadsheet skin. Also overused.

✕

Deep-space base + blue-violet glow + glass cards— the 2021 “AI-generated” standard kit, now the most dated signal there is.

✕

Generic SaaS card grid— gray base, white cards, left gradient bar, chip badges. Swap the content and it still works: that is what template means.

✕

Decoration unrelated to content— mosaics, particles, wave SVGs that are only “pretty”.

05

Walked before every delivery

Content truthfulness. Every numeral matches the source data; multiples and percentages survive arithmetic.

One accent. Every usage matches a role declared in the design plan; no large-area fills.

Zero external dependencies. No web fonts, CDN images or icon libraries; numerals in tabular figures.

Contrast and states. Body text ≥ 4.5:1, large text ≥ 3:1; focus ring ≥ 2px at ≥ 3:1; disabled, loading, empty and error states built, not forgotten.

Verified with screenshots. Headless Chrome — first screen, full length, narrow viewport — inspected with your own eyes.
